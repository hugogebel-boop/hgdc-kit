# hgdc-kit

Le code commun de la H Collection, publié sur npm sous le scope `@hgdc`. Paquets, installation et documentation : [`packages/README.md`](packages/README.md).

Ce dépôt est une copie : le kit se développe avec les modules de Basalte, dans un dépôt privé, et chaque changement arrive ici par un commit automatique (ligne `Basalte-Commit`). Ce dépôt publie ensuite sur npm, avec provenance, et ouvre les PR de mise à jour dans les produits ([runbook](docs/runbooks/publier.md)). Les PR ouvertes ici ne sont pas fusionnées.

Le dépôt est public pour que chaque produit installe le kit sans jeton. Ce n'est pas du logiciel libre : tous droits réservés ([LICENSE](LICENSE)).
