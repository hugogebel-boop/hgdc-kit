Ces composants s'utilisent directement dans une page `.mdx`, sans `import`. Ils portent les mêmes noms que chez Mintlify.

## Encadrés

<Note>Une information utile à côté du texte.</Note>

<Tip>Un conseil qui fait gagner du temps.</Tip>

<Warning>Un piège à éviter.</Warning>

<Danger>Une action qui détruit des données.</Danger>

```mdx
<Note>Une information utile à côté du texte.</Note>
<Tip title="Astuce">Un conseil qui fait gagner du temps.</Tip>
<Warning>Un piège à éviter.</Warning>
<Danger>Une action qui détruit des données.</Danger>
```

`<Info>` et `<Check>` existent aussi. Chacun accepte un `title`.

## Groupe de code

`CodeGroup` réunit plusieurs blocs en onglets, nommés d'après le texte écrit après le langage. Avec `dropdown`, une liste déroulante remplace les onglets.

<CodeGroup>

```bash npm
npm install --save-dev @hgdc/docs
```

```bash bun
bun add --dev @hgdc/docs
```

</CodeGroup>

La même chose avec `dropdown` :

<CodeGroup dropdown>

```bash npm
npm install --save-dev @hgdc/docs
```

```bash bun
bun add --dev @hgdc/docs
```

</CodeGroup>

## Icônes

Les cartes, les étapes et les accordéons prennent une icône, comme chez Mintlify : un nom [Lucide](https://lucide.dev/icons), ou un nom Font Awesome courant (`circle-info`, `gear`…).

  </Card>
  <Card title="Réglages" icon="gear">

</Columns>

## Badge et info-bulle

Une version <Badge color="green" shape="pill">Nouveau</Badge>, un statut <Badge color="orange" icon="clock">Bêta</Badge>, et un <Tooltip tip="Le fichier qui décrit la navigation et l'apparence du site." headline="docs.json">mot expliqué</Tooltip> au survol.

## Champs d'API

<ParamField query="limite" type="number" default="20">
  Nombre de résultats renvoyés, de 1 à 100.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Jeton du projet, précédé de `Bearer`.
</ParamField>

<ResponseField name="pages" type="object[]" required>
  Les pages trouvées.

  <Expandable title="propriétés">
    <ResponseField name="titre" type="string">
      Le titre de la page.
    </ResponseField>
    <ResponseField name="chemin" type="string">
      Son adresse dans le site.
    </ResponseField>
  </Expandable>
</ResponseField>

## Dans le Markdown publié

Chaque composant a une forme Markdown : un encadré devient une citation qui commence par son titre en gras, une étape devient un élément de liste numérotée. C'est cette forme que lisent l'assistant, `llms.txt` et les outils d'IA.
