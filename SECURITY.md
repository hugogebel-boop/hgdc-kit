# Sécurité

Une faille dans un paquet `@hgdc/*` se signale en privé par un [avis de sécurité GitHub](https://github.com/hugogebel-boop/hgdc-kit/security/advisories/new), jamais par une issue publique. Réponse sous trois jours ouvrés.

Les paquets sont publiés uniquement par la CI de ce dépôt (trusted publishing npm, provenance signée). Une version sans attestation de provenance n'est pas de nous.
